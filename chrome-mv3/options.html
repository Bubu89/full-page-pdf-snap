Full Page PDF Snap — Einstellungen

Ganze Seite per Auto-Scroll als hochaufloesendes PDF.

So loest du eine Aufnahme aus (Desktop):
  1. Klick auf das Toolbar-Icon → Popup → Jetzt aufnehmen
  2. Tastenkuerzel Ctrl+Shift+Y
  3. Rechtsklick auf das Toolbar-Icon → Ganze Seite als PDF speichern (auch Schnell-Umschalter fuer Skalierung/Ordner/Sticky)
Was passiert danach: Firefox scrollt die Seite automatisch ganz nach unten, macht bei jedem Sprung einen Screenshot, faedelt alles zu einer PDF zusammen und speichert sie in Downloads/<dein Unterordner>. Bei Erfolg wird der Zielordner geoeffnet (oder das PDF, je nach Einstellung).
So loest du eine Aufnahme aus (Firefox for Android):
  1. Firefox-Menue (drei Punkte oben rechts) → Full Page PDF Snap antippen
  2. Aufnahme startet sofort — kein Zwischen-Popup, kein Dialog
  3. Verlauf sichtbar oben in der Benachrichtigungsleiste ("Erfasse Seite ... XX%")
  4. Wenn fertig: Benachrichtigung "Fertig — X Seiten gespeichert" → antippen um das PDF direkt zu oeffnen
Wichtige Hinweise fuer Android:
  • Der Ziel-Tab muss aktiv bleiben. Bei Tab-Wechsel wechselt die Erweiterung automatisch zurueck
  • Firefox darf nicht in den Hintergrund geschickt werden (Home-Button) — Android pausiert das Rendering, der Screenshot pausiert dann auch
  • PDFs landen in Download/<dein Unterordner>/ — sichtbar in jeder Datei-App unter "Download"
  • Die "Aktion nach Erstellung"-Optionen "Ordner zeigen" sind unter Android nicht verfuegbar (Firefox-API fehlt)

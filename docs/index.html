Features

Built for pages that a normal screenshot cannot handle.

Full-page capture

The complete scrollable page in a single PDF, not just the visible viewport.

Handles lazy loading

Auto-scroll with adjustable delay picks up content that loads while scrolling — LinkedIn, X/Twitter, news portals.

No visible seams

Single-page output stitches all segments into one continuous page. Ideal for OCR and AI tools.

High resolution

Scaling from 1.0x to 2.0x for sharp text and images on long documents.

Filename templates

Compose names from site, date, time, counter and page title.

Hide sticky elements

Cookie banners, chat widgets and floating top bars are removed before capture.

No data collection — by design

This extension contains no technical function to collect, store or transmit usage data. Every step — scrolling, screenshots, PDF generation, saving — happens locally in the Firefox process.

  • The developer never learns which pages you capture
  • No screenshots or PDF files ever leave your device
  • No analytics library, no telemetry, no crash reporting
  • No technical connection to any server of the developer
  • Full source under the MIT license — verify it yourself

Keine Datenerhebung — technisch bedingt

Die Erweiterung enthält keine technische Funktion zur Erhebung, Speicherung oder Übertragung von Nutzungsdaten. Jeder Schritt — Scrollen, Screenshots, PDF-Erzeugung, Speichern — passiert lokal im Firefox-Prozess.

  • Der Anbieter erfährt nie, welche Seiten du erfasst
  • Keine Screenshots und keine PDF-Dateien verlassen dein Gerät
  • Keine Analytics-Bibliothek, keine Telemetrie, keine Fehlerberichte
  • Keine technische Verbindung zu einem Server des Anbieters
  • Vollständiger Quellcode unter MIT-Lizenz — selbst überprüfbar

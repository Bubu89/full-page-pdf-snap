Full Page PDF Snap

Downloads an entire webpage as one seamless PDF — the complete scrolling page on a single continuous sheet, no page breaks, nothing cropped. Runs entirely on the device: no upload, no account, no data collection, and activeTab instead of access to every site you visit. Works in Firefox on desktop and Android, and in Chrome.

PushDictate

Hold Ctrl+Space, speak, release — the transcribed text appears wherever the cursor is blinking. It pastes through the clipboard instead of the Windows text-services layer, which is why it also works in Windows Terminal, PowerShell, WSL, SSH sessions and terminal-based coding agents. That is exactly where the built-in Windows dictation gives up. Push-to-talk, so the microphone opens only while the key is held. Runs with your own OpenAI key; none ships with it.

Citation endpoint (MCP server)

Point it at a URL and it returns what that page declares about itself — authors, title, journal, year, DOI, licence — as a structured record with a ready-to-import RIS entry and BibTeX. Where a page is a paywall, an error or a bot check, it says so and refuses instead of inventing a reference. No account and no key, used in proportion; it reads the page from a server, so anything behind a login stays out of reach and is named as such. Runs at https://provinglab.dev/mcp for any client that speaks MCP, and answers plain curl just as well.

Together. The endpoint collects references at volume but never the document; the extension produces the document with the same fields written into it, and reaches the pages a server cannot — anything behind a login. Both emit the same RIS format, so the results land in one Citavi or Zotero library either way. The workflow in full.

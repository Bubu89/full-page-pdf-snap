Конечная точка собирает ссылки в объёме, но никогда — сам документ; расширение производит документ с теми же записанными в него полями и достаёт страницы, недоступные серверу, — всё за логином. Оба выдают один и тот же формат RIS, поэтому результаты в любом случае попадают в одну библиотеку Citavi или Zotero. Весь рабочий процесс.

Full Page PDF Snap

把整个网页下载为一份无缝 PDF——整个可滚动页面在一张连续的纸上,无分页符、无裁切。完全在设备上运行:无上传、无账户、无数据收集,只请求 activeTab 而非访问你浏览的每个网站。支持桌面端和 Android 的 Firefox,以及 Chrome。

PushDictate

按住 Ctrl+空格,说话,松开——转写文本出现在光标闪烁处。它通过剪贴板粘贴,而不是 Windows 文本服务层,因此在 Windows Terminal、PowerShell、WSL、SSH 会话和终端型编程代理中也能用——正是 Windows 内置听写放弃的地方。按键说话:麦克风只在按住按键时打开。使用你自己的 OpenAI 密钥;不附带任何密钥。

引用端点(MCP 服务器)

把它指向一个 URL,它就返回该页面关于自身的声明——作者、标题、期刊、年份、DOI、许可——作为带可导入 RIS 条目和 BibTeX 的结构化记录。如果页面是付费墙、错误或机器人检查,它会明说并拒绝,而不是编造一条引用。无需账户、无需密钥,请适度使用;它从服务器读取页面,因此登录之后的内容无法到达,并会被如实标明。任何讲 MCP 的客户端都可通过 https://provinglab.dev/mcp 使用,普通的 curl 也同样能应答。

配合使用。 端点可以批量收集引用,但永远不接触文档本身;扩展则生成写入了相同字段的文档,并能到达服务器无法到达的页面——登录之后的一切。两者输出相同的 RIS 格式,因此无论走哪条路径,结果都会进入同一个 Citavi 或 Zotero 文库。完整工作流。

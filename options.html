Full Page PDF Snap — Settings

Save the whole page as a high-resolution PDF via auto-scroll.

How to start a capture (desktop)
  1. Click the toolbar icon → Popup → Capture now
  2. Keyboard shortcut Alt+Shift+Y
  3. Right-click the toolbar icon → Save the whole page as PDF (also quick switches for scaling, folder and sticky handling)
What happens next: the browser scrolls the page to the bottom, takes a screenshot at every step, stitches everything into one PDF and saves it to Downloads/<your subfolder>. On success the target folder opens (or the PDF itself, depending on your setting).
How to start a capture (Firefox for Android)
  1. Browser menu (three dots, top right) → Full Page PDF Snap tap
  2. The capture starts immediately — no intermediate popup, no dialog
  3. Progress is shown in the notification bar ("Capturing page … XX%")
  4. When finished: notification "Done — X pages saved" → tap to open the PDF directly
Important notes for Android:
  • The target tab must stay active. If you switch tabs, the extension switches back automatically
  • Do not send the browser to the background (home button) — Android pauses rendering, and the capture pauses with it
  • PDFs are saved to Download/<your subfolder>/ — visible in any file manager under "Download"
  • The "show folder" options are not available on Android (the API does not exist there)
